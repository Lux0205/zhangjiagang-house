# 张家港房价K线图 桌面软件

一个运行在 Windows 电脑上的软件，自动抓取张家港市五个环区的房价数据，
以 K 线图（蜡烛图）直观展示房价走势。

## 功能简介

- 覆盖张家港市五环区域（一环核心 ~ 五环全市）
- 从 6 个主流房产网站获取房价数据，取中位数聚合
- K 线图直观显示每日开盘、最高、最低、收盘价格
- 支持区域切换和全部对比
- 启动自动更新 + 手动刷新
- 遵守 robots.txt 协议

颜色规则：
- 🔴 红色 = 上涨（收盘价高于开盘价）
- 🟢 绿色 = 下跌（收盘价低于开盘价）

## 安装与运行

### 方式一：直接运行 exe（推荐）

1. 下载 `张家港房价K线图.exe`
2. 双击运行即可

### 方式二：源码运行（需要Python环境）

1. 安装 Python 3.10+
2. 安装依赖：`pip install -r requirements.txt`
3. 运行程序：`python src/main.py`

## 多源数据

| # | 数据源 | 抓取方式 |
|---|--------|----------|
| 1 | 安居客 | requests（静态） |
| 2 | 房天下 | requests（静态） |
| 3 | 张家港房产网 | requests（静态） |
| 4 | 贝壳找房 | Playwright（动态） |
| 5 | 链家网 | Playwright（动态） |
| 6 | 58 同城 | requests（静态） |

## 免责声明

数据来源于公开网络，仅供参考，不构成投资建议。
房价数据以张家港市住建局官方备案为准。
抓取频率已做限制（请求间隔≥5秒），遵守 robots.txt 协议。

## 开发说明

技术栈：Python + PyQt6 + SQLite + ECharts

```
src/
├── main.py              # 程序入口
├── ui/                  # 界面代码
├── scraper/             # 爬虫模块（6个数据源）
├── data/                # 数据库操作
└── utils/               # 工具（配置/日志/聚合算法）
```

打包命令：`python build.py` → 输出 `dist/张家港房价K线图.exe`
