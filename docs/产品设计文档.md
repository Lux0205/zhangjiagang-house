# 张家港房价K线图软件 — 产品设计文档

## 一、产品概述

一个运行在 Windows 桌面上的软件，自动抓取张家港市五个环区的房价数据，
以 K 线图（蜡烛图）形式直观展示房价走势。

## 二、目标用户

- 张家港本地居民，关注房价走势的普通人
- 需要简单了解各区域房价变化的购房者
- 对编程零基础的用户（界面必须操作直观）

## 三、覆盖区域（五环划分）

### 一环（市中心核心）
- 范围：步行街、人民路、长安路周边
- 参考小区：置地甲江南、中港花苑、蓝波金典、胜利新村
- 当前均价：约 9000-15500 元/㎡

### 二环（杨舍镇主城区）
- 范围：二环以内的主城区
- 参考小区：花园浜、亨通花园、西湖苑、观唐、湖滨国际
- 当前均价：约 8000-27000 元/㎡

### 三环（近郊镇区）
- 范围：塘桥镇区、金港街道
- 当前均价：约 10000-13200 元/㎡

### 四环（外围镇区）
- 范围：锦丰镇、凤凰镇、乐余镇、南丰镇、大新镇核心区域
- 当前均价：约 9750-11000 元/㎡

### 五环（全市范围）
- 范围：全市8个镇
- 当前均价：约 8946 元/㎡（全市二手房均价）

## 五、数据格式

### 原始数据（每套房屋一条）
```json
{
  "date": "2026-07-13",
  "region": "一环",
  "community": "置地甲江南",
  "price": 15426,
  "unit": "元/㎡",
  "source": "安居客",
  "fetch_time": "2026-07-13T10:30:00"
}
```

### K线数据（每区域每天一条）
```json
{
  "date": "2026-07-13",
  "region": "一环",
  "open": 14800,
  "high": 15500,
  "low": 14200,
  "close": 15426,
  "volume": 5,
  "avg": 15000
}
```

### 多源聚合规则
- 每个区域的均价取多个数据源的**中位数**
- 去除明显异常值（超过均值 ±30% 的数据剔除）
- 至少需要 2 个以上数据源有数据时才计算

## 六、界面设计

### 布局
```
┌──────────────────────────────────────────────┐
│  张家港房价K线图  v1.0      [刷新]  最后更新  │
├──────────────────────────────────────────────┤
│  [一环] [二环] [三环] [四环] [五环] [全部对比] │
├──────────────────────────────────────────────┤
│                                              │
│              K 线 图（ECharts）               │
│                                              │
├──────────────────────────────────────────────┤
│  当前区域：一环   最新均价：15426 元/㎡         │
│  涨跌：+2.3% (较昨日)                        │
├──────────────────────────────────────────────┤
│  数据来源：安居客/房天下/贝壳等6个网站         │
│  ⚠ 数据仅供参考，不构成投资建议               │
└──────────────────────────────────────────────┘
```

### 交互逻辑
1. 启动软件 → 自动更新数据（后台静默，不阻塞界面）
2. 点击区域按钮 → 切换显示该区域K线图
3. "全部对比" → 五条线叠加显示
4. "刷新"按钮 → 手动重新抓取数据
5. 进度条显示抓取进度

### 颜色规则
- 上涨：红色（收盘价 > 开盘价）
- 下跌：绿色（收盘价 < 开盘价）
- K线图使用标准蜡烛图样式

## 八、技术方案

- **界面框架**：PyQt6
- **K线图库**：ECharts（通过 QWebEngineView 嵌入）
- **数据存储**：SQLite
- **爬虫**：requests + Playwright
- **打包工具**：PyInstaller → Windows .exe
- **安装方式**：单文件 .exe 即开即用
